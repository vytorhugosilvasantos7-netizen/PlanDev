    Sobre o PlanDev

    O PlanDev é um workspace para quem programa: um lugar para organizar projetos, mostrar seu código funcionando, preparar o portfolio, acompanhar entrevistas e manter as metas em dia.

    Você cola o HTML, CSS e JavaScript do projeto e ele roda na hora, numa área isolada e segura. O portfolio ainda passa por uma verificação que aponta o que falta para ficar em perfeitas condições.

    A comunidade exibe apenas projetos e portfólios que seus donos escolheram publicar. Seu e-mail não é exibido publicamente. A comunidade compartilhada exige o backend PlanDev hospedado; GitHub Pages sozinho não oferece banco ou API.

    A agenda de entrevistas avisa quando o dia se aproxima e quando chega. O Pomodoro ajuda a estudar com foco.

    Feito com HTML, CSS e JavaScript.
